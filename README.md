# HaulSync

HaulSync keeps every GTA client's recipients, GSTR-1 work, bank reconciliation, settings and backups separate. One license covers unlimited clients on one Windows computer.

- **Download:** https://github.com/yaiz2702/haulsync-releases/releases/latest/download/HaulSync-Setup.exe
- **Store:** https://yasir.tailab7a7c.ts.net
- **Landing page:** https://yaiz2702.github.io/haulsync-releases/

## Install

Run `HaulSync-Setup.exe`. The installer is per-user and does not need an administrator account. The build is not code-signed yet, so Windows SmartScreen may show a warning: choose **More info**, then **Run anyway**.

## Data

Client data stays on the customer's computer under `%LOCALAPPDATA%\HaulSync\data\clients`. Uninstalling removes the program but keeps data and activation.
